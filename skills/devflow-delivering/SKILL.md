# Deliver and reconcile

Input: authorized endpoint, current candidate/proof, saved actions and outstanding findings/accounting. Output: independently verified endpoint evidence or a recoverable blocker.

Start from `work show` and `next`. Reuse valid evidence for direct delivery without inventing implementation. Send repairs through [coordinating](../devflow-coordinating/SKILL.md) and obtain affected independent gates.

Journal supported mutations before dispatch, including branch publication through `push_branch`. Bind local head, repository, remote ref and expected remote head; use the dispatcher instead of raw `git push`. Publish a regular PR after independent remote head readback. Read [external operations](references/external-operations.md) for mutation and reconciliation mechanics.

On uncertainty, reconcile the same action before retrying. Only definite no-mutation failure permits `action retry`; preserve prior receipts. Do not replace an action/work ID to hide failed dispatch. A changed prerequisite or compatible workflow upgrade does not erase failure.

Publish every confirmed code finding as an anchored PR review thread. Keep rejected/unanchorable publication outstanding. After independent fix verification and pushed fix proof, reply, resolve and independently read back. A real deferral uses `finding defer` with an actual linked follow-up and rationale, stays open, and obeys repository merge policy.

Before completion, import available selected-session usage and record `usage account` completeness for this candidate. Unknown/unavailable attribution or prices include their source and limit; absence is not zero. Preserve coordination, failed attempts and repairs in accounting.

Re-read source/target refs, required CI, current gates, findings and endpoint. Queued merge or mismatched integrated tree is incomplete. Use supported protected delivery; unsupported capabilities remain blocked. Explicit user-controlled merges follow their authorized native path and must not be relabeled as automatically protected delivery.

Finalize after actual receipt and independent endpoint readback. Report implemented, verified, published and merged accurately. Release the claim when the endpoint is proved. For installation/upgrades, follow the [installation procedure](references/installation.md) with a manifest and preserved history.

Handoff missing proof to [verifying](../devflow-verifying/SKILL.md), native-role recovery to [coordinating](../devflow-coordinating/SKILL.md), and missing scope to [defining-work](../devflow-defining-work/SKILL.md). Retain the outcome through recovery.
