# Delivery

Read current `next`, candidate, authority, required gates, and outstanding findings. Review-only and merge-only work reuse valid existing evidence and start at their actual phase.

Publish each confirmed code finding as its own PR review thread with a stable marker and valid line/file anchor. Reconcile uncertain API responses before retrying. An unanchorable finding remains blocked; a timeline summary does not satisfy its review-comment obligation.

After independent technical verification, current gates, and pushed fix proof, reply with the fixing reference and sanitized verification, resolve the thread, and independently read it back. A real deferral remains open with its linked work. Local-only delivery may retain pending publication; later publication makes those obligations due.

Before remote mutation, commit an action intent. Dispatch only the recorded operation within authority, then record the actual receipt and independent readback. Current source/target refs and enforced protection must match the proof. Unsupported protection/stack/queue capabilities remain explicit blockers. A queued merge is not completion.

Read the resulting commit/tree and target reachability. A mismatch is exposed-unverified: preserve history, pause further delivery, and reconcile. Never automatically revert user work. Record Done only for the proved authorized endpoint. Report unsynchronized Project state separately.
