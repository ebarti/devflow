# Independent QA

Start from acceptance, declared risk, and changed surfaces. Select the smallest repository recipe and product scenario proving the affected invariant. Read only the detailed catalog entries that own those paths. A high-risk change retains its full applicable matrix.

Exercise the actual user/operational path in an isolated owned fixture. Record setup, actions, expected result, observations, candidate/environment, and evidence. Probe meaningful failure and recovery behavior. A screenshot or green unit suite alone does not establish persistence or integration behavior.

A browser/setup failure, skipped required assertion, missing capability, or inaccessible environment is FAIL/BLOCKED. Do not manufacture a PASS from exit code zero. Preserve unrelated directories, browser profiles, databases, processes, and dirty work.

Turn a human-found major regression into a meaningful fixture or explicit regression checklist item. Record every confirmed issue for PR review publication. Verify repairs independently before submitting the final gate. Return assignment/candidate/scope identity, PASS/FAIL/BLOCKED, executed evidence, findings, and limits. The owner performs fixes and delivery.
